# src/payments/ 에이전트 규칙

이 폴더는 **활성 결제 코드**입니다 (`src/billing/`, `src/old/`는 DEPRECATED — 여기서 참조 금지).

## 금액 단위
- 모든 금액은 **전(minor unit) 정수**로 다룬다 (`amountMinor`). 부동소수점 원 단위 금지.
- 수수료 계산은 `REFUND_FEE_RATE` 상수 × 금액 → `Math.floor`로 내림. 계산식 자체를 임의로 바꾸지 말 것.

## 로그
- 결제 관련 로그는 **`lib/logger.js`의 `logPayment()`만** 사용한다. `console.log`/`logInfo`/`logError` 직접 호출 금지.
- `logPayment()`는 `{ event, orderId, amountMinor, feeAmountMinor, currency, status }`를 받아 `{ ts, event, order_id, amount_minor, fee_amount_minor, currency, status }` 고정 스키마 JSON 한 줄을 출력한다. `amount_minor`는 수수료 차감 후 실환불액(net), `fee_amount_minor`는 차감된 수수료.
- 새 이벤트를 추가할 땐 `refund.<상태>` 형태의 이벤트 이름으로 구분하고(예: `refund.rejected_zero_amount`), 고정 스키마에 없는 필드를 로그에 임의로 추가하지 않는다.

## 테스트
- 이 폴더의 코드를 바꾸면 **반드시 `npm test`를 실행**해서 통과를 확인한다 (`tests/refund.test.js`가 이 모듈을 검증함).

자세한 환불 규칙(수수료 계산 원칙 · 검증 · 에러 처리)은 [payment-rules.md](../../docs/payment-rules.md) 참조.
