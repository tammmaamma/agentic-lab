# Mini Spec — 학번 유효성 검사기

> 코드 작성 전 스펙 정리 단계. 이 문서는 구현을 담지 않는다.

## ① What

```
validateStudentId(id: string): { valid: boolean, reason?: string }
```

- 입력 형식: `"D2026-1234"` — `D`(대문자 고정) + 입학년도 4자리 + 하이픈(`-`) + 일련번호 4자리. 이 형식과 정확히 일치해야 한다 (앞뒤 잉여 문자 없이 전체 일치).
- 형식에 맞으면 `{ valid: true }`, 아니면 `{ valid: false, reason: "..." }`을 반환한다.
- `reason`은 아래 2종의 고정 문자열 중 하나다 (자유문장이 아닌 고정 값 — 호출부에서 분기 가능하도록):
  - 정규식 자체가 불일치(대소문자·공백·하이픈·자릿수·타입 등 모든 형식 문제 포괄): `"학번 형식이 아닙니다 (예: D2026-1234)"`
  - 정규식은 일치하지만 입학년도가 유효 범위를 벗어남: `` `입학년도가 유효 범위(2000~${올해})를 벗어났습니다` ``
- 판정 순서: **① 정규식 형식 일치 여부를 먼저 검사 → ② 통과한 경우에만 연도 범위(2000~올해)를 검사**. 즉 형식 오류가 있으면 연도가 범위 안이어도 형식 오류로 거부되고, 형식은 맞는데 연도만 범위 밖이면 연도 오류로 거부된다.

## ② Why

- 잘못된 학번 입력으로 인한 데이터 오류 **0건**이 목표.
- 검증 실패 시 원인을 알 수 없으면 디버깅·사용자 안내가 불가능하므로, 실패한 경우 **반드시 `reason`을 함께 돌려준다**.

## ③ Constraints

- 외부 라이브러리 사용 금지 — 정규식과 표준 내장 기능만 사용한다.
- 입학년도는 **2000년 이상, 올해 이하**(양끝 포함, inclusive)만 유효. `올해`는 호출 시점의 `new Date().getFullYear()`로 계산한다 (파라미터로 주입받지 않음 — 시그니처는 `id` 단일 인자로 유지). 이 함수는 호출 시점에 따라 결과가 달라질 수 있는 **시간 의존 함수**임을 인지한다.
- 대소문자·공백은 **정규화(변환)하지 않는다** — 입력을 있는 그대로 정규식으로만 판정한다. 트림·대문자 변환 등은 이 함수의 책임이 아니다 (④ "형식 검증만 한다" 원칙과 일관).

## ④ Boundaries (범위 밖)

이 함수는 **형식 검증만** 한다. 아래는 명시적으로 범위 밖:

- 실제 재학 여부 조회 (학사 시스템 연동 등)
- DB 접근
- UI/입력 폼 처리

## ⑤ Edge cases

- 빈 문자열
- 소문자 `d` (예: `d2026-1234`)
- 하이픈 누락 (예: `D20261234`)
- 연도 1999 (범위 밖, 과거)
- 미래 연도 (범위 밖, 올해 초과) — `올해`는 시스템 시계 기준이라, 테스트에서는 하드코딩된 연도(예: 2030) 대신 **호출 시점 기준 `현재연도 + 1`** 같은 동적 값으로 검증한다
- 일련번호 3자리 (예: `D2026-123`)
- 일련번호 5자리 (예: `D2026-12345`)
- 앞뒤 공백 (예: `" D2026-1234 "`)
- non-string 입력 (`null`, `undefined`, 숫자 등) — 형식에 맞을 수 없으므로 무효
- 패턴 뒤 잉여 문자로 인한 부분매치 (예: `"D2026-1234X"`) — 무효
- 하이픈 2개 이상 (예: `"D2026-12-34"`) — 무효
- 전각(fullwidth) 하이픈 `－`(U+FF0D) 사용 — 무효

## 정책 결정 (readiness 감리 후 확정)

이전 미결 질문 4개를 ④ "형식 검증만 한다" 원칙에서 도출해 아래처럼 확정함:

1. **대소문자** — 정규화하지 않음. 소문자 `d`는 무효(거부).
2. **공백** — 트림하지 않음. 앞뒤 공백이 있으면 그 자체로 형식 불일치(무효).
3. **연도 경계** — 2000, 올해 양끝 **포함**. `올해`는 호출 시점 시스템 시계로 계산(파라미터 주입 없음) — 이 함수는 시간 의존적임을 감수.
4. **reason 형태** — 자유문장이 아닌 고정 문자열 2종(① 참조). 우선순위는 **형식 검사 → 연도 범위 검사** 순서 (동시에 여러 형식 문제가 있어도 정규식은 한 번에 판정되므로 "형식 오류" 하나로 합쳐짐).
